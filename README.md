# Exponential Surge

ระบบสร้างสื่อการสอนและพัฒนาทักษะของตัวเอง — หัวข้อแรกคือการเงิน

**เป้าหมาย:** จบหลักสูตรแล้วสร้างโมเดล DCF ได้เองใน Google Sheets และประเมินมูลค่าหุ้นไทย 1 ตัวได้จริง
**ผู้เรียน:** สัตวแพทย์ที่มีความรู้การเงินน้อยมาก
**แหล่งความรู้แรก:** *Valuation*, 7th ed. (Koller, Goedhart, Wessels — McKinsey & Wiley, 2020)

## เริ่มเรียน

ดับเบิลคลิก `index.html` — ไม่ต้องต่อเน็ต ไม่ต้องติดตั้งอะไร

ถ้าเบราว์เซอร์บล็อกอะไรบางอย่าง ให้เปิดผ่านเซิร์ฟเวอร์แทน:

```bash
python -m http.server 8765
```

แล้วเข้า http://localhost:8765

## โครงสร้าง

| ที่อยู่ | คืออะไร |
|---|---|
| `index.html` | แดชบอร์ดหลักสูตร ความคืบหน้า ปุ่มส่งออกสถานะ |
| `review.html` | คิวทบทวนกันลืม รอบ 1 · 3 · 7 · 14 · 30 · 60 วัน |
| `data/curriculum.js` | นิยามหลักสูตรและแหล่งความรู้ — เพิ่มเล่มใหม่ที่นี่ |
| `engine/` | เครื่องยนต์กลาง: ควิซ · simulator · กันลืม · สไตล์ |
| `modules/NN-*/` | เนื้อหา ศัพท์ เกม เคส แผนที่ต้นฉบับ และบันทึกของผู้เรียน |
| `knowledge/case-company.md` | งบการเงินบริษัทสมมติที่เดินเรื่องทั้งหลักสูตร — **ห้ามแก้** |
| `knowledge/insights.md` | คลังข้อสรุปและข้อผิดพลาดสะสม |
| `scripts/extract_source.py` | สกัดข้อความจาก PDF ลง `_source/` |
| `scripts/build_pages.py` | แปลง `.md` ของโมดูลเป็น `.html` ที่อ่านในเบราว์เซอร์ได้ — รันใหม่ทุกครั้งที่แก้ `.md` (`notes.md` กลายเป็นหน้า "สมุดบันทึก" ฟอร์มในเว็บ) |
| `scripts/notes_from_progress.py` | แปลงข้อความสมุดบันทึกใน `progress.json` กลับเป็น `modules/NN/notes.md` ไว้เป็นประวัติใน git |
| `progress.json` | สถานะที่ส่งออกจากเบราว์เซอร์ ไว้ให้ Claude อ่าน |

## เกณฑ์ผ่านแต่ละโมดูล

1. อ่าน `concept.md`
2. เล่นเกมหลักของโมดูล
3. ทำควิซ
4. ทำ `case.md` โดยไม่เปิดเนื้อหา
5. เขียนสมุดบันทึก (หน้า "สมุดบันทึก" ในเว็บ — เซฟอัตโนมัติ ส่งออกรวมใน `progress.json`) อธิบายกลับด้วยภาษาตัวเอง

ข้อ 4 กับ 5 คือเกณฑ์จริง ที่เหลือคือทางไปถึงมัน

## ความคืบหน้าเก็บที่ไหน

เบราว์เซอร์เขียนไฟล์บนดิสก์เองไม่ได้ สถานะจริง (ควิซ เกณฑ์ผ่าน และข้อความในสมุดบันทึก) จึงอยู่ใน localStorage
กด **ส่งออก progress.json** ที่หน้าแรกหรือท้ายสมุดบันทึก แล้วบันทึกทับไฟล์ `progress.json` เมื่อต้องการให้ Claude เห็นสถานะล่าสุด — Claude จะรัน `scripts/notes_from_progress.py` เพื่อเขียนสมุดบันทึกลง `notes.md` ให้เอง

## กติกาที่ห้ามละเมิด

1. เนื้อหาเขียนใหม่เป็นภาษาไทย **ไม่ใช่งานแปล** ยกข้อความต้นฉบับได้เฉพาะประโยคนิยามสั้นๆ พร้อมอ้างอิงบท
2. **ห้ามมีข้อมูล CPF** ในเนื้อหา ตัวอย่าง หรือเคสใดๆ
3. **ห้ามใช้บริษัทในเครือ CP เป็นเคสฝึก**
4. `_source/` และไฟล์ PDF ต้นฉบับไม่เข้า git
5. `notes.md` คือบันทึกส่วนตัว แยกจากไฟล์เนื้อหาเสมอ เพื่อให้แจกทีมได้โดยไม่ต้องมานั่งคัดทีหลัง
