# ศัพท์โมดูล 1

คงคำอังกฤษไว้ทุกคำ เพราะงบการเงินจริง (56-1, annual report) และบทวิเคราะห์ทั้งหมดเป็นภาษาอังกฤษ

| ไทย | อังกฤษ | ความหมายสั้นที่สุด |
|---|---|---|
| เงินทุนที่ลงไป | invested capital | เงินที่จมอยู่ในกิจการเพื่อให้ดำเนินงานได้ = เงินทุนหมุนเวียน + ที่ดินอาคารอุปกรณ์ |
| เงินทุนหมุนเวียน | working capital | สต็อก + ลูกหนี้ − เจ้าหนี้การค้า |
| ที่ดิน อาคาร อุปกรณ์ | property, plant, and equipment (PP&E) | สินทรัพย์ถาวรที่ใช้ดำเนินงาน |
| กำไรจากการดำเนินงานหลังภาษี | NOPAT (net operating profit after taxes) | กำไรดำเนินงานหลังภาษี **ก่อน** หักดอกเบี้ย |
| ผลตอบแทนต่อเงินทุนที่ลงไป | ROIC (return on invested capital) | NOPAT ÷ เงินทุนที่ลงไป |
| ต้นทุนเงินทุน | cost of capital | ผลตอบแทนขั้นต่ำที่นักลงทุนเรียกร้องสำหรับความเสี่ยงระดับนั้น |
| ค่าเสียโอกาส | opportunity cost | ผลตอบแทนที่เสียไปจากการไม่เอาเงินไปลงที่อื่น — เป็นคำที่ตรงกว่า "ต้นทุนเงินทุน" |
| กำไรเชิงเศรษฐศาสตร์ | economic profit | (ROIC − ต้นทุนเงินทุน) × เงินทุนที่ลงไป |
| กระแสเงินสดคิดลด | discounted cash flow (DCF) | วิธียุบผลงานอนาคตทั้งหมดให้เหลือตัวเลขเดียว ณ วันนี้ |
| มูลค่าที่แท้จริง | intrinsic value | มูลค่าที่คำนวณจากกระแสเงินสดในอนาคต ต่างจากราคาตลาด |
| กำไรต่อหุ้น | EPS (earnings per share) | กำไรสุทธิ ÷ จำนวนหุ้น — ตัวเลขที่ถูกใช้ผิดบ่อยที่สุด |
| ผลตอบแทนรวมของผู้ถือหุ้น | TSR (total shareholder returns) | ส่วนต่างราคาหุ้น + เงินปันผล |
| โรคระยะสั้น | short-termism | การไล่ตามตัวเลขระยะสั้นจนทำลายมูลค่าระยะยาว |
| ตลาดจริง | real market | ตลาดที่กิจการทำเงินจริงจากลูกค้าจริง |
| ตลาดการเงิน | financial market | ตลาดที่ราคาหุ้นถูกตั้งจากความคาดหวังของนักลงทุน |
| ผลกระทบภายนอก | externalities | ผลกระทบต่อคนที่ไม่ได้อยู่ในสมการของบริษัท เช่น มลพิษ |
| ความได้เปรียบเชิงแข่งขัน | competitive advantage | เหตุผลที่ ROIC สูงอยู่ได้นาน (ลงลึกโมดูล 4) |

## คำที่ฟังคล้ายกันแต่คนละเรื่อง — ห้ามสับสน

| | คืออะไร | ใช้ตัดสินอะไร |
|---|---|---|
| **กำไรสุทธิ** (net income) | เหลือหลังหักทุกอย่างรวมดอกเบี้ย | บอกผลรวม ไม่บอกว่าธุรกิจเก่งไหม |
| **NOPAT** | กำไรดำเนินงานหลังภาษี ก่อนดอกเบี้ย | ธุรกิจเก่งไหม โดยไม่ปนเรื่องกู้เงิน |
| **กระแสเงินสดอิสระ** (free cash flow) | NOPAT หักเงินที่ต้องลงทุนกลับเพื่อโต | เงินที่เจ้าของถอนออกได้จริง |
