# ศัพท์โมดูล 2

คงคำอังกฤษไว้ทุกคำ เพราะงบการเงินจริง (56-1, annual report) และบทวิเคราะห์ทั้งหมดเป็นภาษาอังกฤษ

| ไทย | อังกฤษ | ความหมายสั้นที่สุด |
|---|---|---|
| กระแสเงินสดอิสระ | free cash flow (FCF) | NOPAT − เงินลงทุนสุทธิ = เงินสดที่กิจการผลิตได้จริงและจ่ายคืนเจ้าของ/เจ้าหนี้ได้โดยไม่กระทบการโต |
| เงินลงทุนสุทธิ | net investment | เงินทุนที่ลงไปปลายปีนี้ − ปลายปีก่อน = เงินที่เอากลับไปจมเพิ่มในกิจการ |
| อัตราลงทุนซ้ำ | investment rate (IR) | เงินลงทุนสุทธิ ÷ NOPAT = สัดส่วนของกำไรที่เอากลับไปลง — และ = g ÷ ROIC |
| อัตราการเติบโต | growth (g) | อัตราที่ NOPAT และกระแสเงินสดโตต่อปี — ในสูตรหมายถึงโตคงที่ตลอดไป |
| ต้นทุนเงินทุนถัวเฉลี่ย | weighted average cost of capital (WACC) | ผลตอบแทนที่นักลงทุนทุกกลุ่มคาดหวังจากกิจการ = อัตราคิดลดของ FCF — โมดูลนี้รับ 9% ไว้ก่อน คำนวณจริงโมดูล 11 |
| สูตรตัวขับเคลื่อนมูลค่า | key value driver formula | มูลค่า = NOPAT × (1 − g ÷ ROIC) ÷ (WACC − g) — ใช้ได้เมื่อ g < WACC และทุกอย่างคงที่ตลอดไป |
| ผลตอบแทนของเงินก้อนใหม่ | return on new invested capital (RONIC) | ROIC เฉพาะเงินลงทุนที่เพิ่งลงไป อาจต่างจาก ROIC เฉลี่ยของเงินทั้งก้อน — โมดูล 8 |
| ตัวคูณกำไร | earnings multiple · P/E | มูลค่า ÷ กำไร — สูตรบอกว่ามันถูกกำหนดด้วยทั้ง g และ ROIC ไม่ใช่แค่ g |
| หลักอนุรักษ์มูลค่า | conservation of value | อะไรที่ไม่เพิ่มกระแสเงินสด ไม่เพิ่มมูลค่า — เปลี่ยนคนถือหรือเปลี่ยนหน้าตาบัญชีไม่นับ |
| การซื้อหุ้นคืน | share repurchase · buyback | บริษัทซื้อหุ้นตัวเองกลับ หุ้นลดลง EPS เพิ่ม — แต่เงินสดของกิจการไม่เพิ่ม |
| การขยายตัวคูณ | multiple expansion · rerating | ความเชื่อว่ากำไรของกิจการที่ถูกซื้อจะถูกตีราคาด้วยตัวคูณของผู้ซื้อ — ไม่มีข้อมูลจริงรองรับ |
| ขายแล้วเช่ากลับ | sale-leaseback | ขายสินทรัพย์ที่ยังใช้อยู่ให้คนอื่นแล้วเช่ากลับ — งบดูเบาลงแต่ค่าเช่ามักแพงกว่าดอกเบี้ย+ค่าเสื่อม |
| วิศวกรรมการเงิน | financial engineering | การใช้เครื่องมือหรือโครงสร้างทางการเงินนอกเหนือจากหนี้และทุนธรรมดา — ส่วนใหญ่ไม่สร้างมูลค่า เว้นแต่เปลี่ยนเงินสดจริง (เช่นภาษี) |
| ลู่วิ่ง | treadmill | ภาพเปรียบเมื่อ ROIC = WACC: โตเท่าไหร่มูลค่าก็อยู่ที่เดิม (คำของหนังสือ) |
| ผลิตภาพของเงินทุน | capital productivity | รายได้ต่อเงินทุนที่ลงไป — อีกทางหนึ่งในการขึ้น ROIC นอกจากเพิ่มอัตรากำไร |

## คำที่ฟังคล้ายกันแต่คนละเรื่อง — ห้ามสับสน

| | คืออะไร | ใช้ตัดสินอะไร |
|---|---|---|
| **กำไร (NOPAT)** | สิ่งที่กิจการทำได้ในปีนั้น | ธุรกิจเก่งไหม — แต่ยังไม่บอกว่าเหลือเงินเท่าไหร่ |
| **กระแสเงินสดอิสระ (FCF)** | กำไรหลังหักเงินที่เอากลับไปลงซ้ำ | มูลค่า — เพราะนี่คือเงินที่เจ้าของได้จริง |
| **ROIC (เฉลี่ย)** | กำไร ÷ เงินทุนทั้งก้อนที่จมอยู่ | กิจการโดยรวมสร้างมูลค่าไหม |
| **RONIC (เงินก้อนใหม่)** | กำไรที่เพิ่ม ÷ เงินที่เพิ่งลงเพิ่ม | การโตครั้งนี้คุ้มไหม — ตัวนี้ที่ตัดสินอัตราลงทุนซ้ำจริง |
| **มูลค่า (value)** | กระแสเงินสดอนาคตคิดลด | กิจการ "น่าจะ" มีค่าเท่าไหร่ |
| **ราคา (price)** | สิ่งที่ตลาดยอมจ่ายวันนี้ | มีความคาดหวังรวมอยู่ — ซื้อแพงกว่ามูลค่า = ได้ผลตอบแทนต่ำ |
| **ตัวคูณสูงเพราะโตเร็ว** | g สูง | ยังไม่พอ — ต้องถาม ROIC ด้วย |
| **ตัวคูณสูงเพราะ ROIC สูง** | โตช้าก็ตัวคูณสูงได้ | บริษัทโตช้าที่ ROIC สูง มักถูกมองข้ามว่า "แพง" ทั้งที่พอดี |
